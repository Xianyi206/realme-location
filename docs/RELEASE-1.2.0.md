# 定点助手 1.2.0（预发布测试版）

Android 8.0 及以上的固定坐标模拟工具，支持保存和管理多个命名地点。

本版将日常操作拆分为「定位」「地点」「设置」，增加独立地点编辑页、名称搜索、删除确认和未保存修改提示。选中目标与当前模拟位置分别展示，点击开始或切换后才改变模拟坐标。

## 下载与升级

下载 Release 附件 `DingDianHelper-1.2.0.apk`，按 README 完成模拟位置权限设置。原版本用户应直接覆盖安装以保留地点；覆盖升级尚待真机验证。卸载或清除应用数据会删除已存地点。

`SHA256SUMS.txt` 用于核对附件完整性，`verification.json` 记录验证范围和源码哈希。仓库不包含签名私钥；自行生成签名的安装包不能覆盖原作者签名的版本。

## 验证边界

已通过 44 个 Java 核心测试和 11 个桌面 Chrome 地图案例，完成 APK 编译、签名及对齐校验。浏览器测试覆盖地图页面，不代表 Android 原生界面测试通过。

尚未验证真机安装与覆盖升级、原生界面、手机当前位置采集、Android 服务与定位源集成、realme 后台运行及浏览器实际接收的位置。此版本应标记为预发布测试版。
